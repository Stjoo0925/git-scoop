# Git Scoop Development Rules

- Respond in English.
- Write code comments in English and update them alongside the code.
- Do not modify files outside the requested scope.
- If you do not know, ask rather than guess.
- Do not make a fix without knowing the cause.
- Do not write temporary code or insecure code.
- Remove debug logs after resolving the problem.
- Search the web before solving complex problems.
- Maintain production quality.
- Run builds only as needed for the changed scope.
