## Ground-truth Datasets

The primary calibration and validation histories each contain 600 labeled connections across 50 functions and 12 transitions, plus explicit root creation and final deletion. They use distinct seeds, source identifiers, and commit IDs. Event labels come from authored scenario rules, not from the genealogy engine.

The full suite contains 11 datasets and 1,210 required connections. Eight forbidden automatic connections guard against mistaken identity continuations. Forbidden links are prohibited regardless of their proposed event labels.

| Dataset | Evidence and expected behavior |
| --- | --- |
| calibration | Creation, body/signature changes, renames, file moves, simultaneous changes, deletion |
| validation | A separate 600-link history with the same event coverage and a distinct seed |
| copy | Original remains present; a copy must not replace its identity |
| ambiguous | Duplicate bodies with simultaneous renames remain ambiguous |
| methods | Same-name methods in different impl owners stay distinct |
| types | Struct rename/change, enum change, trait declarations/default methods, trait impl context, file move |
| merge | Two actual parents; a symbol absent from the first parent is imported rather than newly created there |
| shallow | A real depth-one clone with an unavailable ancestor; creation is unconfirmed |
| malformed | Broken Rust syntax is incomplete evidence rather than proof of deletion |
| missing-object | A deliberately unavailable blob in a newly created fixture repository |
| split | Function splitting has no unique automatic continuation |

The JSON oracle records actual commit IDs, ordered parents, symbol names/kinds/contexts, source byte ranges, event labels, required connections, prohibited connections, and boundary states. The tests compare independently authored expectations with actual Git blobs and Tree-sitter declarations. Fixture creation uses fixed identities, dates, line endings, and SHA-1 repositories; global/system Git configuration and dangerous inherited Git path overrides are excluded.

## Performance Fixture

The benchmark has exactly 1,000 first-parent commits, 200 Rust files at HEAD, and 10,485,760 source bytes. Each file contains 500 functions, followed by bounded comment padding to keep the agreed total size exact. The benchmark therefore has 100,000 declarations at HEAD. One file changes per later commit. The seed, message sequence, timestamps, commit IDs, and file contents are reproducible.

The generator uses a single [Git fast-import stream](https://git-scm.com/docs/git-fast-import) rather than spawning a separate commit process 1,000 times. The shallow fixture uses local cloning with depth one and local-copy optimization disabled. [Git clone documentation](https://git-scm.com/docs/git-clone)

This is a controlled synthetic performance workload. It does not establish performance on real projects, release latency, precision, or recall. Those targets remain subject to CGE-011 validation.
